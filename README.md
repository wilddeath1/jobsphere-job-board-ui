# 💼 JobSphere - Job Board UI Concept

A responsive and modern job board interface built with **React** and **Vite**.

JobSphere is a fictional job platform created as a frontend learning project to practice reusable React components, dynamic rendering, state management, responsive navigation, and interactive UI development.

🔗 **Live Demo:** https://wilddeath1.github.io/jobsphere-job-board-ui/

## ✨ Features

* 📱 Responsive desktop and mobile layout
* 💼 Dynamic job listing cards
* 🧩 Reusable React components
* 🍔 Mobile hamburger navigation menu
* 🔖 Save / Unsave job interaction
* 🔗 External application links
* 📊 Data-driven UI rendering
* 🎨 Clean and modern job board design
* ⚡ Interactive UI with React state

## 🛠️ Tech Stack

* **React**
* **JavaScript**
* **Vite**
* **CSS3**
* **Lucide React**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/wilddeath1/jobsphere-job-board-ui.git
```

### 2. Navigate to the project

```bash
cd jobsphere-job-board-ui
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal.
